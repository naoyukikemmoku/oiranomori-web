# テントサイズ検索データ

来場者が自分のテント名で引いて、適合サイトを判断するための表示用データ。
**サイトを選ぶ指標であり、寸法の厳密さを保証するものではない。**

## ファイル

| ファイル | 内容 |
|---|---|
| `all.csv` | 全14メーカー結合版（449製品）。表示用にはこれを使う |
| `<maker>.csv` | メーカー別。all.csv の分割元 |

## 列

| 列 | 内容 |
|---|---|
| `maker` / `name` / `model_no` / `aliases` | メーカー・製品名・型番・別名（色違い等を `;` 区切り） |
| `status` | 現行 / 廃番 / 不明 |
| `long_cm` / `short_cm` / `height_cm` | 外寸の長辺・短辺・高さ |
| `area_m2` | 長辺×短辺（m²、小数1桁） |
| `long_m` | 長辺（m） |
| `class` | 小型 / 中型 / 大型 / 超大型 |
| `source_url` / `source_type` / `checked_date` | 出典 |
| `flag` | 数値の確度・注意事項。**必ず参照する** |

## クラス判定

面積と長辺のどちらか一方でも超えたら上のクラス。

| クラス | 面積 | 長辺 |
|---|---|---|
| 小型 | ≤8.3m² | ≤3.6m |
| 中型 | ≤19.2m² | ≤6.4m |
| 大型 | ≤28.4m² | ≤6.4m |
| 超大型 | 上記以外 | |

## データの確度（3層）

`source_type` と `flag` で判別できる。**表示時は確度を区別せず使ってよいが、
問い合わせ対応で「公式値です」と断言してよいのは第1層のみ。**

### 第1層：公式値（262件 / `source_type=公式`）

メーカー公式サイトに使用時サイズ（組立サイズ・展開サイズ・本体サイズ）の
数値記載があったもの。DOD・キャプテンスタッグ・LOGOS・バンドック・
テンマクデザイン・コールマン・WAQ・モンベル・Naturehike の大半。

### 第2層：二次情報の実寸（117件 / `flag` に「二次情報で確認」「販売店掲載値」等）

公式が使用時サイズを公開していないため、販売店・レビュー記事等の掲載値を採用。
スノーピーク・ogawa・ゼインアーツの主要モデルが該当。
`要確認` が付いているものは単一出典のみで裏取りができていない。

### 第3層：推定値（70件 / `flag` に「寸法推定」）

公式・二次とも寸法が見つからなかったもの。公式の**総重量と定員**から
床面積を推定し、そこから長辺・短辺を割り出している。

推定モデル: `面積(m²) = 2.05 × 重量(kg)^0.759 × 1.27`（重量と定員を 45:55 で加重）

- メーカーが寸法も重量も出している122製品で較正（DOD 74 / バンドック 32 / 実寸確認済み16）
- **クラス一致率は約67%**。外れる場合もクラス境界で1段階ずれる程度
- 1.27倍の補正は、素の回帰が実測より約27%小さく出るため（前室・キャノピー・
  張り綱の張り出しは面積を増やすが重量はさほど増えない）。
  サイト選びでは小さく見積もる方が危険なので上振れ側に寄せている

## 既知の弱点

- ゼインアーツ・サバティカル・OneTigris・ogawa は公式が寸法を画像でしか出さない
  （SVGは文字がパス化、取説PDFはフォント埋込、ogawa仕様PDFはスキャン画像）ため、
  第2層・第3層に依存している
- 2026年新作（ゼインアーツ KIIRA / YOMA / TAO 等）は寸法未公表で推定値
- 円錐・台形など不定形は外接長方形として扱っている
- セット品（テント＋タープ）は構成要素のどれの寸法か不明なものに `範囲要確認` を付与

## 更新方法

生成スクリプトはリポジトリ外（作業用一時ディレクトリ）にある。
再生成が必要な場合は、各メーカー公式サイトのスクレイプから作り直す必要がある。
寸法を1件だけ直す場合は該当 CSV を直接編集し、`flag` に根拠を追記して
`all.csv` を作り直す（`all.csv` は各メーカーCSVの単純結合）。

## 二次情報の調査記録（ogawa / OneTigris の限界）

ogawa は**販売店経由でも使用時サイズが取れない**ことを確認済み。

- ナチュラムでogawa製品94件分を検索し、実在したのは21件。その21件すべて
  スペック欄が `収納サイズ` のみで使用時サイズの記載なし
  （ホズST 2605 / タッソUL / シャンティR / ピレウス / アステロイド /
  ヒュッテレーベン / タッソT/C 等で確認）
- 販売店はメーカーのスペック文をそのまま転載するため、
  メーカーが出していない項目は販売店にも存在しない
- レビュー記事で個別に実測を載せている主要モデル（ティエラ/アポロン/
  オーナーロッジ52R/ツインクレスタ/ピルツ15/タッソ/グロッケ8・12/
  ステイシーST-II）は第2層として取得済み

OneTigris も同様に公式ストアが寸法非公開で、日本語レビュー記事から
個別に取得できた分（CONIFER / NEBULA / JOVIAN / SOLO HOMESTEAD /
ROCDOMUS / Rock Fortress / ROC SHIELD）のみ第2層。
