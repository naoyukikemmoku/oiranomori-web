## 先に結論

- **来る人を迷わせる指示が2つある。** FAQ は「住所で検索して」と書き、アクセスのページは「住所検索では別の場所に案内される」と書いている（#1）。ディープは「場所非公開」と書きながら、利用案内の場内マップに県道名と周りの建物が載っている（#2）。
- **ディープ側の3ページ（/deep/・/stay-deep/・/deep-guide/）が、条件と決まりの説明に寄っている。** 設備がないこと、18歳以上・1〜3名、禁止事項が何度も出る。「合わない人」「準備はできたか」と読み手を試す言い方もある（#7〜#12）。ライト側（/stay-light/・/light-guide/）は、トーンガイドにおおむね沿っている。
- **FAQ は、初めに「予約・キャンセル」の7問しか見えない。** ほかの質問があることに気づきにくい（#3）。
- **IT系の言い回しは少ない。** FAQ とディープ利用案内の「完結」、FAQ の「オンライン操作」「操作期限」が目立つ程度。

## 見解が分かれたもの

### 26. ディープ利用案内の禁止事項に、トーンガイド §6 を当てるか
- **Claude Code の見方**
  - §6 は「禁止・ルールの書き方」で、「ルール一覧の冒頭に『楽しんでもらうための共通ルール』と明示」と書いている。利用案内のルールの節こそ §6 の対象と読むべき。そうでないと §6 を当てる場所がない。
  - deep-guide:268「禁止事項（厳守）」は理由のない並べ立てで、前置きもない。:333「利用者が守るべき、この森の精神的基盤です」は読み手に向けた断定（§4）。
  - ライトの利用案内は §6 どおり（light-guide:446「同じ森に泊まる人どうしが、気持ちよく過ごすための約束ごとです」、各ルールに理由）。差が大きい。
- **Codex の見方**
  - 基準1は「機能説明のページ・箇所」を §3〜§6 の対象外としている。利用案内の禁止事項はルールの機能説明なので、§6 違反の根拠にはならない。ライトが §6 に沿っていても、ディープに当てる義務は生じない。
  - 「目的のない「お散歩」」の境目が分からない点は、基準4で拾える（#7 に入れた）。
- **ナオに決めてほしいこと**：利用案内のルールの節を §6 の対象とするか。対象とするなら、ディープの禁止事項をライトと同じ書き方（お願い＋理由）にするか。「野グソ禁止」（:340）をナオの声として残すか。

### 27. FAQ のサイト選びの「ソロで直火・野営感」

### 28. 「何もしない贅沢」の冒頭の三つの問いかけ
